# SpartanGO Design Mockups

## Overview

This folder contains the design mockups and prototype for SpartanGO, a shuttle app designed for Norfolk State University students.

## Figma Prototype

The Figma prototype demonstrates the planned interface and user experience for the SpartanGO shuttle app.

[View SpartanGO Figma Prototype](https://www.figma.com/make/WqLhckbYghFcrFntmJCEg2/Redesign-Shuttle-Experience?fullscreen=1&t=qoAO33bhmLIhzktr-1&code-node-id=0-6)

## Design Goals

- Provide an easy-to-use shuttle tracking interface.
- Display shuttle locations and estimated arrival times.
- Support on-demand ride requests.
- Simplify student boarding through QR codes.
- Maintain Norfolk State University's green and gold branding.
